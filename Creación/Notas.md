# Material de referencia y concepto visual

## 1. Material útil para comenzar

### MediaPipe

[MediaPipe](https://google-ai-edge.github.io/mediapipe-samples-web/#/vision/face_detector)

MediaPipe contiene diferentes herramientas que pueden utilizarse para trabajar con **visión artificial**, incluyendo detección y seguimiento de personas, rostros y otros elementos visuales.

Para el proyecto, la intención es utilizar MediaPipe como sistema de **tracking de personas** y conectar esta información con **TouchDesigner**.

### MediaPipe + TouchDesigner

Existe un proyecto específico que permite conectar MediaPipe con TouchDesigner:

[MediaPipe TouchDesigner — GitHub](https://github.com/torinmb/mediapipe-touchdesigner)

Este recurso puede servir como punto de partida para obtener información del tracking directamente dentro de TouchDesigner y utilizarla para modificar los visuales en tiempo real.

## 3. Concepto del visual

Por ahora, la idea se centra en construir una experiencia visual que funcione como una especie de **radiografía digital de una persona**.

El visual todavía no tiene definido exactamente qué elemento o estructura será representada, pero debería estar relacionado conceptualmente con el EP:

> **«Todo lo sólido se disuelve»**

El concepto del EP gira alrededor de una idea de transformación y superación: **todo aquello negativo o difícil eventualmente pasa y existe una posibilidad de encontrar luz al final del túnel**.

A partir de esto, el visual podría explorar la transformación progresiva de una figura humana:

**persona → radiografía → descomposición → transformación → luz**

La intención es que el tracking no sea únicamente una herramienta técnica, sino que tenga un significado dentro de la experiencia: **el cuerpo del espectador se convierte en el elemento que activa y modifica la representación visual.**

## 5. Dirección conceptual inicial

La propuesta busca combinar tres elementos principales:

### Tracking

El movimiento y la posición de la persona son detectados mediante **MediaPipe** y utilizados dentro de **TouchDesigner**.

### Radiografía

El cuerpo puede representarse mediante una estructura visual que revele algo que normalmente no vemos: huesos, órganos, partículas, líneas, energía o algún otro elemento abstracto.

### Transformación

La figura no permanece estática. A medida que la persona interactúa con el sistema, su representación puede **descomponerse, cambiar de estado o transformarse**, haciendo referencia a la idea de que *todo lo sólido se disuelve*.

El resultado debería transmitir una sensación de **oscuridad, transformación y eventual aparición de luz**, sin necesariamente representar literalmente el concepto.

# Concepto visual — Orquideorama

## *Todo lo sólido se disuelve*

La propuesta visual se construirá como **una única transformación continua**. No habrá cuatro escenas completamente independientes, sino cuatro **estados de una misma materia** que evoluciona progresivamente a lo largo del EP.

La figura humana será el elemento central de la experiencia. El cuerpo del espectador funcionará como materia que puede ser reconocida, duplicada, descompuesta y finalmente llevada hacia un umbral de luz.

El recorrido general será:

> **Materia → Memoria → Disolución → Umbral**

Y visualmente:

> **Cohesión → Repetición → Dispersión → Suspensión**

---

# Escena 1 — Materia

### *Rosa mentirosa*

**Estado conceptual:** choque / aparición del problema / dolor.

En esta primera etapa, la figura humana se encuentra relativamente **completa y cohesionada**. El sistema reconoce al espectador y construye una representación digital de su cuerpo.

La intención no es realizar una radiografía médica literal, sino crear una **interpretación estructural del cuerpo**: una figura compuesta por puntos, líneas, estructuras y elementos visuales que permitan reconocer la presencia de una persona.

La representación debe sentirse todavía **estable**.

Sin embargo, comienzan a aparecer pequeñas alteraciones que indican que algo no está completamente bien. La estructura puede presentar pequeñas vibraciones, desplazamientos, fracturas o anomalías.

### Lenguaje visual

* Figura humana reconocible.
* Estructura relativamente sólida.
* Puntos y líneas conectados.
* Movimiento contenido.
* Pequeñas deformaciones.
* Interferencias o anomalías progresivas.
* Sensación de tensión.

### Concepto

> **La materia todavía está completa, pero algo dentro de ella ha cambiado.**

La escena representa el primer contacto con el problema: todavía no existe una transformación completa, solamente la aparición de una grieta.

---

# Transición 1 → 2

La transición debe ser **progresiva y casi imperceptible al principio**.

Las alteraciones que aparecen en *Rosa mentirosa* comienzan a dejar rastros.

Una posición del cuerpo ya no desaparece inmediatamente cuando el espectador se mueve, sino que permanece durante un instante.

La figura comienza a generar **ecos de sí misma**.

La estructura pasa lentamente de:

> **una figura**

a:

> **una figura + rastros de figuras anteriores.**

Esto introduce el siguiente estado sin realizar un cambio abrupto de escena.

---

# Escena 2 — Memoria

### *A veces duele*

**Estado conceptual:** negación / repetición / imposibilidad de procesar lo ocurrido.

En esta etapa la figura todavía puede reconocerse, pero comienza a existir acompañada de **versiones anteriores de sí misma**.

La representación visual puede generar ecos, duplicaciones y rastros de movimiento.

Cuando el espectador mueve un brazo, por ejemplo, la representación actual puede convivir durante unos instantes con las posiciones anteriores:

```text
       ●
      / \
     ●   ●

        ●
       / \
      ●   ●

           ●
          / \
         ●   ●
```

La figura parece estar atrapada entre diferentes momentos.

### Lenguaje visual

* Duplicación.
* Rastros.
* Ecos.
* Persistencia.
* Repetición.
* Desplazamientos temporales.
* Superposición de estados anteriores.
* Movimiento que deja memoria.

### Concepto

> **La persona continúa intentando procesar algo que todavía no puede aceptar.**

La representación no necesita volverse más caótica. Por el contrario, puede volverse **obsesivamente repetitiva**.

La figura intenta permanecer estable, pero constantemente vuelve a encontrarse con sus propios rastros.

---

# Transición 2 → 3

Los ecos comienzan a perder estabilidad.

Al principio:

> figura → eco → figura.

Después:

> figura → eco → fragmento.

Los rastros dejan de desaparecer completamente y empiezan a **separarse de la estructura principal**.

Los elementos que antes servían para reconstruir el cuerpo comienzan a desprenderse.

La memoria deja de ser solamente una repetición y empieza a convertirse en **materia dispersa**.

---

# Escena 3 — Disolución

### *Días tristes de agosto*

**Estado conceptual:** aceptación / adaptación / depresión.

En esta etapa la persona comienza a aceptar una nueva realidad.

Visualmente, esto se representa mediante la **pérdida progresiva de cohesión de la figura**.

La estructura humana ya no tiene que permanecer completamente conectada.

Los puntos pueden comenzar a separarse.

Las líneas pueden romperse.

Los elementos pueden alejarse de su posición original.

Sin embargo, la figura todavía debe ser parcialmente reconocible.

```text
        ·  ·
      · ● ·
    ·  / \   ·
      ●   ●
   ·    \    ·
       ●
          ·
```

### Lenguaje visual

* Dispersión.
* Fragmentación.
* Pérdida de conexiones.
* Partículas.
* Separación.
* Movimiento lento.
* Menor estabilidad.
* Restos de la estructura original.

### Concepto

> **La realidad ya no se niega. Ahora hay que aprender a vivir dentro de ella.**

La disolución no representa necesariamente destrucción.

Representa la pérdida de la forma anterior.

La persona sigue existiendo, pero su estructura inicial ya no puede mantenerse de la misma manera.

---

# Transición 3 → 4

La disolución continúa hasta que la figura pierde progresivamente su capacidad de reconocerse como cuerpo.

Pero los elementos que se desprenden no desaparecen.

En lugar de desaparecer completamente, comienzan a **moverse en una dirección común**.

La dispersión comienza a organizarse.

La materia que estaba flotando alrededor de la figura empieza lentamente a orientarse hacia una fuente de luz.

La transición es:

> **dispersión → organización**

Pero esta nueva organización ya no reconstruye necesariamente el cuerpo.

---

# Escena 4 — Umbral

### *Luces del amanecer*

**Estado conceptual:** final / incertidumbre / posibilidad.

La figura llega al punto en el que su forma original prácticamente ha desaparecido.

Frente a ella aparece una **fuente de luz**.

La luz no representa necesariamente felicidad, salvación o una solución.

Representa simplemente:

> **el final de un camino y el comienzo de algo desconocido.**

La persona se encuentra frente a ese límite.

No sabemos si va a avanzar.

No sabemos si quiere hacerlo.

No sabemos qué existe detrás.

### Lenguaje visual

* Suspensión.
* Espacio.
* Pocos elementos.
* Partículas flotantes.
* Luz progresiva.
* Contraste entre oscuridad y luminosidad.
* Figura parcialmente reconocible.
* Sensación de espera.

### Concepto

> **Todo aquello que formaba a la persona se ha transformado. Ahora queda decidir qué hacer frente a lo que viene.**

La escena no debe resolver completamente el recorrido.

La incertidumbre es parte del final.

---

# Flujo completo

Las cuatro escenas forman un único proceso:

```text
                 TODO LO SÓLIDO SE DISUELVE

                         PERSONA
                            │
                            ▼
                    ┌─────────────┐
                    │   MATERIA   │
                    │             │
                    │  COHESIÓN   │
                    └──────┬──────┘
                           │
                       fractura
                           │
                           ▼
                    ┌─────────────┐
                    │   MEMORIA   │
                    │             │
                    │ REPETICIÓN  │
                    └──────┬──────┘
                           │
                         eco
                           │
                           ▼
                    ┌─────────────┐
                    │ DISOLUCIÓN  │
                    │             │
                    │ DISPERSIÓN  │
                    └──────┬──────┘
                           │
                     organización
                           │
                           ▼
                    ┌─────────────┐
                    │   UMBRAL    │
                    │             │
                    │ SUSPENSIÓN  │
                    └─────────────┘
                           │
                           ▼
                         LUZ
```

## Principio fundamental

Las escenas **no deben sentirse como cuatro visuales diferentes**.

El objetivo es que, si alguien observa el proyecto sin conocer las canciones, pueda percibir que está viendo **el mismo cuerpo atravesando una transformación continua**.

Por eso cada estado debe conservar elementos del anterior:

**Materia** contiene el origen de la **Memoria**.

**Memoria** contiene el origen de la **Disolución**.

**Disolución** contiene el origen del **Umbral**.

Y el **Umbral** conserva los restos de todo lo que ocurrió anteriormente.

| Aceptación     | Pérdida de cohesión                |

| Incertidumbre  | Permanencia frente a la luz        |

## Regla general del proyecto

> **No representar literalmente las canciones. Representar el estado de la materia a medida que la persona atraviesa las canciones.**

De esta manera, **el cuerpo del espectador no solamente activa el visual: se convierte en la materia narrativa del EP.**
