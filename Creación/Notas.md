# Material de referencia y concepto visual

## 1. Material útil para comenzar

### MediaPipe

[MediaPipe](https://google-ai-edge.github.io/mediapipe-samples-web/#/vision/face_detector)

MediaPipe contiene diferentes herramientas que pueden utilizarse para trabajar con **visión artificial**, incluyendo detección y seguimiento de personas, rostros y otros elementos visuales.

Para el proyecto, la intención es utilizar MediaPipe como sistema de **tracking de personas** y conectar esta información con **TouchDesigner**.

### MediaPipe + TouchDesigner

Existe un proyecto específico que permite conectar MediaPipe con TouchDesigner:

[MediaPipe TouchDesigner — GitHub](https://github.com/torinmb/mediapipe-touchdesigner)

Este recurso puede servir como punto de partida para obtener información del tracking directamente dentro de TouchDesigner y utilizarla para modificar los visuales en tiempo real.

## 2. Referente visual

### Massive Attack + United Visual Artists

Como referente principal se plantea el trabajo visual desarrollado para **Massive Attack** por **United Visual Artists (UVA)**:

[Massive Attack — United Visual Artists](https://www.dezeen.com/2026/06/08/massive-attack-united-visual-artists/)

El objetivo inicial es **emular algunos de estos principios**, pero llevándolos hacia una propuesta propia relacionada con la identidad visual de la banda y su música.

## 3. Concepto del visual

Por ahora, la idea se centra en construir una experiencia visual que funcione como una especie de **radiografía digital de una persona**.

El visual todavía no tiene definido exactamente qué elemento o estructura será representada, pero debería estar relacionado conceptualmente con el EP:

> **«Todo lo sólido se disuelve»**

El concepto del EP gira alrededor de una idea de transformación y superación: **todo aquello negativo o difícil eventualmente pasa y existe una posibilidad de encontrar luz al final del túnel**.

A partir de esto, el visual podría explorar la transformación progresiva de una figura humana:

**persona → radiografía → descomposición → transformación → luz**

La intención es que el tracking no sea únicamente una herramienta técnica, sino que tenga un significado dentro de la experiencia: **el cuerpo del espectador se convierte en el elemento que activa y modifica la representación visual.**

## 5. Dirección conceptual inicial

La propuesta busca combinar tres elementos principales:

### Tracking

El movimiento y la posición de la persona son detectados mediante **MediaPipe** y utilizados dentro de **TouchDesigner**.

### Radiografía

El cuerpo puede representarse mediante una estructura visual que revele algo que normalmente no vemos: huesos, órganos, partículas, líneas, energía o algún otro elemento abstracto.

### Transformación

La figura no permanece estática. A medida que la persona interactúa con el sistema, su representación puede **descomponerse, cambiar de estado o transformarse**, haciendo referencia a la idea de que *todo lo sólido se disuelve*.

El resultado debería transmitir una sensación de **oscuridad, transformación y eventual aparición de luz**, sin necesariamente representar literalmente el concepto.
